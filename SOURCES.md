## What has been checked

- The independent website's build, navigation, content routes, and practice-package file checks.
- Installation instructions against the cited upstream documentation.
- Command syntax checks are reported separately in the relevant tutorial when they have actually been performed.

## What has not been checked

- Installation of every coding agent and toolkit integration on every operating system.
- Independent execution of every upstream game example.
- Compilation, development-client execution, and installed-JAR execution of the Copper Token practice package.

Treat source review, successful installation, successful compilation, and a mod working in a running game as separate milestones. An upstream field note records the upstream author's work; it is not an independent test result from this guide.

Tutorial prose is newly assembled for this independent field guide. Upstream names, commands, screenshots, assets, and code retain their original attribution and applicable licenses. This repository does not redistribute the upstream toolkit or game files.
